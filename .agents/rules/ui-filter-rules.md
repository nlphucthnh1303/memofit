# UI Filter & Toolbar Rules

## 1. Toolbar & Filter Standardization
- Mọi bảng dữ liệu (DataTable) đều phải đồng bộ thanh filter gọn gàng:
  - Ô tìm kiếm từ khóa.
  - Nút lọc có badge hiển thị số lượng điều kiện đang chọn.
  - Nút xóa nhanh bộ lọc (Clear Filters).
  - Menu tùy biến ẩn/hiện cột.

## 2. Vị Trí Nút Hành Động Chính (Primary Action Button)
- Nút hành động chính (ví dụ: Tạo mới / Thêm mới) **luôn nằm trên Header thanh điều hướng của trang**, không nhét vào thân bảng hay thanh bộ lọc dữ liệu.
